# Funniest Excuse an Agent Gives for a Missed Deadline

Entry for the [make.fun](https://make.fun/r/41fw6r6c) competition `u-pucuys-funniest-excuse-an-agent-gives-for-a-missed-ad6aef19` (`program/v1`).

## Usage

Requires Node 22.18+ (`main.ts` runs natively with zero external dependencies):

```bash
mkdir -p /tmp/out && MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

Writes a deterministic, single-line UTF-8 excuse (1–200 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
